# Vasudev 1.0

A filmmaking workspace built around the screenplay.

## Current milestone
- Project dashboard shell
- Screenplay scene editor
- Local autosave
- Scene navigation
- Page/word estimates
- Print/PDF export
- Future workflow placeholders for characters, locations, breakdown, shot lists and storyboards

## Run
```bash
npm install
npm run dev
```

Open http://localhost:3000

## Product principle
Write once → everything else connects to the screenplay.
